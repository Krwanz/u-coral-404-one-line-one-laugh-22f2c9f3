A [make.fun](https://make.fun/c/u-coral-404-one-line-one-laugh-22f2c9f3) bounty entry: one funny line, at most 200 characters, judged head-to-head by an AI comedy editor.

## The line

> I asked my AI assistant for a joke; it opened my calendar, stared at my schedule, and laughed for three minutes straight.

## How it works

`main.ts` writes the line to `/output/entry.txt` (121 characters, one line, UTF-8). Run it with Node 22+:

```sh
node main.ts
```

The line was written to land on a first read: a small setup, then a turn the reader does not see coming — the assistant judging the schedule instead of telling a joke.
